<summary>About this directory — what it is, what it isn't, and how to add an organisation</summary>
<p>Maintained by DOD members as a monitoring resource — to keep track of what different groups are doing and how the broader landscape is evolving.</p>
<p>These are not affiliated or partner organisations. Individuals from some of these groups participate in our discussions, but there is no formal association. Entries aim to be neutral and factual.</p>
<p>The ℹ️ button beside each name opens a quick profile — what the organisation does, and either its next event or the last major one it held. Hover it, tap it, or tab to it; click to keep the card open, <code>Esc</code> to dismiss. It is a browsing aid, not a substitute for the organisation's own page, which carries the full timeline and sourcing.</p>
<p>To add an organisation, <a href="https://github.com/DesigningOpenDemocracy/DesigningOpenDemocracy.github.io">open a pull request</a> or raise it in the <a href="https://t.me/joinchat/HNk_UBX8A7jBPJPbAZU5Zg">Telegram channel</a>.</p>
