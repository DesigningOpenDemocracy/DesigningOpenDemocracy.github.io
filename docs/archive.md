# Landscape Archive

<!-- Out of the tab bar (see mkdocs.yml's not_in_nav): there are already 11
     tabs, and this is reached from News and the Calendar's past list. -->

Every past event recorded across the Democracy Landscape, newest first: the long memory behind [Landscape News](news.md), which covers only the last three months' major and notable events, and the [calendar](calendar.md), which covers what's coming up.

<details class="plain-details page-about-details">
<summary>About this page</summary>
<p>Each row is an event from an organisation's own page in the <a href="/organisations/">Democracy Landscape</a>, with the same citation: the title links to the source, and the organisation's name to its profile. <strong>★</strong> marks a major event and <strong>●</strong> a notable one; the rest are the routine milestones an editor chose to record. Events shared by co-hosts appear once, with every organisation named.</p>
<p>This is what DOD has recorded, not a complete history of any organisation: coverage is thin before an organisation was added to the landscape, and dense after. Know of something missing? Add it as an event on the organisation's page with a source, by <a href="https://github.com/DesigningOpenDemocracy/DesigningOpenDemocracy.github.io">pull request</a> or in the <a href="https://t.me/joinchat/HNk_UBX8A7jBPJPbAZU5Zg">Telegram channel</a>.</p>
</details>
